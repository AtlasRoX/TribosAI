    Configuration reference

    Every environment variable read by tribos/ and app/ (tests excluded). Types, defaults and descriptions come from the settings registry (tribos/config/settings.py); the "Read at" column comes from scanning the code. Regenerate with python scripts/gen_env_reference.py; CI can run it with --check, which also fails when a variable read in the code is not registered. A commented template is in .env.example.

    At startup the API validates the environment (tribos.config.validate_environment): unparsable or out-of-range numbers, unknown choices, non-boolean flags and TRIBOS_* names that no code reads (likely typos) are logged as warnings, counted in config_problems on /api/health, and fail startup only with TRIBOS_STRICT_CONFIG=1. Invalid values fall back to the default.

    Precedence for state directories: a specific variable (TRIBOS_MEMORY_DIR, TRIBOS_RUNS_DIR, TRIBOS_UPLOAD_ROOT, TRIBOS_JOBS_DIR, TRIBOS_TOOL_CACHE_DIR) wins over TRIBOS_DATA_DIR; with neither set, every store keeps its historical location under the workspace.
