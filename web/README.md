# Tribos — Web Application

> **Tribos** — Engineering & Scientific R&D Web Interface  
> **Made by ChronoStrider Engineering**

This is the Next.js frontend application for **Tribos**, the engineering, mathematics and scientific research assistant.

## Getting Started

### 1. Prerequisites
- Node.js 20+ (Node 22+ recommended)
- Running Tribos FastAPI backend (default: `http://127.0.0.1:8000`)

### 2. Run the Development Server

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to access the Tribos research interface.

### 3. Build & Production

```bash
npm run typecheck
npm run test
npm run build
npm start
```

## Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Backend API:** Connects to Tribos FastAPI via `NEXT_PUBLIC_API_URL` (default `http://127.0.0.1:8000`)
